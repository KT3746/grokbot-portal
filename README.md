# Sala de Jogos

Portal em português (PT-BR) com **somente links** para os jogos.
Nenhum jogo é hospedado neste repositório — a página é um lançador estático.

Site: [https://kt3746.github.io/grokbot-portal/](https://kt3746.github.io/grokbot-portal/)

## O que é isto

Um hub (HTML, CSS e um pouco de JavaScript) que aponta para outros sites no GitHub Pages.
Se você clicar em **Jogar**, sai desta página e entra no jogo (nova aba).

- `index.html` — estrutura da página
- `styles.css` — visual
- `hub-mobile.css` — ajustes de toque / safe-area
- `app.js` — dica, press juice, tilt; wave2: jogados hoje, chips, Surpresa; wave3: Continuar, contagem do filtro, haptic, selo Novo; wave4: favoritos ★, ordenar (Novo/A–Z/Recente), Continuar com blurb + glow, haptic reforçado
- `js/bg3d.js` — fundo 3D (pausa fora da aba)
- `.github/workflows/pages.yml` — publica o site no GitHub Pages
